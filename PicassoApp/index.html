Как добавить текст на открытку?

Выберите способ: сгенерировать с помощью ИИ-конструктора или заполнить поля вручную.

Конструктор промта

Настройте параметры, нажмите «Создать промт» и скопируйте результат.

+ Пол М/Ж (выбор)
+ Должность
+ Стиль (душевное/официальное)
Текст промта
Заполните текстовые поля

Нажмите на поле — введите текст. Ограничение по символам учитывается автоматически.
